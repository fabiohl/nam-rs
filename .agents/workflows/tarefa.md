# Automatizador de Tarefa Técnica conforme /TODO-sprints.md (caso não exista, crie-o)

Acionar a skill `planejador-arquiteto` para planejar a execução no Agent Manager de uma Tarefa ou Sprint conforme `/TODO-sprints.md` (caso não exista, crie-o).
Entenda minunciosamente os objetivos do projetoNAM-rs, inclusive pesquisando as fontes citadas.
Se for fornecido uma tarefa (Exemplo: "Tarefa 1.2") o objetivo é a implementação desta tarefa conforme explicado na sua descrição.
Se for fornecido uma sprint (Exemplo: "Sprint 1") o objetivo é passar em revista/auditoria todo a sprint para assegurar que todos os objetivos micro e macro daquela sprint foram cumpridos. Aproveitar para atualizar as documentações como README.md e docs/architecture.md.
Ao final da conclusão das atividades, se houver alguma obervação relevante a ser deixada para as próximas tarefas, deixar anotado no /TODO-sprints.md no local mais adequado.
Se, ao final da revisão geral da sprint, forem identificados apontamentos relevantes de melhorias - grandes demais para ser resolvido na atividade atual - é permitido a melhoria das tarefas e/ou sprints posteriores à que está sendo revisada. Ou mesmo a adição de nova(s) sprint(s) e tarefa(s) ao final.
Havendo tomadas de revisão relevantes, também verificar se há impacto no restante do /TODO-sprints.md e fazer as devidas notas nos locais afetados.
