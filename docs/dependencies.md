# Dependências do Projeto NAM-rs

Esta documentação lista e detalha contextualmente as dependências de sistema operacional e de software englobadas no `Cargo.toml`. O objetivo principal é justificar a necessidade destas abstrações frente às rígidas regras de arquitetura e performance (em detrimento de libs mais ricas ou bloated).

## 1. Dependências do Sistema (Linux)

Os seguintes pacotes de bibliotecas primárias devem estar instalados no sistema via `apt` ou pacote correspondente no seu ambiente para viabilizar as bindings C do *PipeWire* através de abstrações nativas.

* **`pipewire`** e **`libpipewire-0.3-dev`**: Headers e libraries do core de processamento e backend PipeWire. Únicas portas nativas para comunicação direta dos Context e Loop da rotina RT;
* **`clang`** e **`libclang-dev`**: Utilitários compiladores para transcrever de forma automática os headers C/C++ para ffi nativa no *rust-bindgen* durante *build-time*;
* **`pkg-config`**: Ferramenta elementar que expõe os apontamentos dos diretórios do `pipewire` às rotinas de ambiente lib nativo.

## 2. Abstrações de Software (Crates - Cargo.toml)

| Crate                          | Versão Fixada | Função Primordial e Justificativa de Arquitetura                                                                                                                                                                                                                                                                                         | Alternativas Consideradas                                                                                                                                                      |
| ------------------------------ | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **`anyhow`**                   | `^1.0`        | Transição enxuta das sinalizações de erro nas threads de preparação e CLI, limitando uso de unwrap()/panic() passíveis de falhas fatais.                                                                                                                                                                                                 | Rejeitado erro padronizado *Result* com Enums própios em prol da sintaxe ágil.                                                                                                 |
| **`crc32fast`**                | `^1.5`        | Implementação de validações algébricas *Cyclic Redundancy Check* essenciais à assinatura digital dos contêineres `.namb` (*Tone3000*), padrão IEEE 802.3.                                                                                                                                                                                | *crc*: recusado devido a menor especialização a altas velocidades e pipeline otimizado do crc32fast.                                                                           |
| **`ctrlc`**                    | `^3.5`        | Abstrai chamadas para processar o sinal abortivo `SIGINT`. Propaga o indicador atômico internamente aos Handlers PipeWire para shutdown polido de contexto RT.                                                                                                                                                                           | Interceptação em `libc`, preterido por complexidade *unsafe* injustificável e maior verbosidade inter-thread.                                                                  |
| **`libc`**                     | `^0.2`        | Vinculação fundamental à C Standard Library, fornecendo privilégios brutos requeridos nas invocações POSIX (`pthread_setschedparam` = `SCHED_FIFO`) e escalonamentos de PID thread core affinity de cpu isolado.                                                                                                                         | Interfaces encapsuladoras via crates isolados geram arrastos que a documentação C desmantela facilmente.                                                                       |
| **`pipewire`**                 | `0.9.x`       | Implementação portável não oficial expondo a API `libpipewire 0.3`. Reduz o impacto de criar todo o wrapper das interfaces Node de áudio e Buffers a partir do C e provê infraestrutura ThreadLoop e MainLoop assíncronas.                                                                                                               | *jack*, preterido de acordo as missivas fundacionais em priorizar tecnologia nativa de PipeWire no ecossistema Linux Moderno mitigando a fragmentação do *Audio Daemon*.       |
| **`rtrb`**                     | `0.3.x`       | Mantenedor vital do Ring Buffer e transações elementares na mecânica de espera Single-Producer/Single-Consumer (*SPSC*). Usado exclusivamente nas parametrizações que escapam do *Time Predictable Engine* e não travam *(lock-free)* a Thread RT de simulação matemática (exs: model change, samplerate trigger, hot_resampler switch). | *crossbeam*, detém overhead desnecessário para SPSC puro.                                                                                                                      |
| **`serde`** e **`serde_json`** | `^1.0`        | Deserialização em *startup* time do formato padrão não estruturado `.nam`.                                                                                                                                                                                                                                                               | Parser próprio, recusado pelas inconsistências comunitárias nos *strings mappings* e conversões de chaves complexas aninhadas em *Float32 Matrices*.                           |
| **`lexopt`**                   | `0.3.x`       | Parseador espartano e isento de alocações por debaixo dos panos, extraindo argumentos (`--model`, `--input-gain`) sem intercessão de Macros ou instâncias abstratas.                                                                                                                                                                     | *clap*: preterido porque eleva a poluição e aumenta o peso do executável com funcionalidades inatingíveis pela pragmática modesta da CLI da IA.                                |
| **`rubato`**                   | `0.16.x`      | Malha polinomial Sinc-Filter usada para atenuar as diferenças brutas inter-processuais quando a porta de hardware e taxa do pipeline nativamente diferem dos `48000 Hz` exigidos pelos tensores da rede (*Kaiser Sinc* bidirecional).                                                                                                    | Desestimou-se transição à *branch 2.x* perante obrigatoriedade sistêmica acoplada ao componente *audioadapter*, maculando restritiva de zero-overhead em rotinas vetoriais RT. |

| Crate           | Versão Fixada | Função Primordial e Justificativa de Arquitetura                                                                                                                                                                                          |
| --------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
