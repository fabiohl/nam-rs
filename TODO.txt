# ============================================================================
# Modelos .nam para Testes de Integração e Benchmarks
# ============================================================================
#
# Vários testes de integração (tests/nam_infer_test.rs) e benchmarks
# (benches/inference_bench.rs) dependem de modelos .nam reais para
# executar. Quando estes modelos não estão presentes, os testes imprimem
# "SKIP: <motivo>" e retornam sem falhar.
#
# Para ativar todos os testes e benchmarks, siga estas instruções:
#
# ── 1. Origem dos modelos ──────────────────────────────────────────────
#
#   Os modelos vêm do treinador oficial do NAM:
#     https://tonehunt.com/
#     https://github.com/sdatkinson/neural-amp-modeler
#
#   Modelos pré-treinados de exemplo para teste já estão incluídos no
#   repositório C++ de referência:
#     github.com/mikeoliphant/NeuralAudio/Utils/Models/
#
#   Modelos presentes (já no repo, usados pelos testes atuais):
#     - BossWN-standard.nam  (WaveNet Standard, CH=16, ~284KB)
#     - BossWN-feather.nam   (WaveNet Feather, CH=8, ~65KB)
#     - BossWN-nano.nam      (WaveNet Nano, CH=4, ~18KB)
#     - BossLSTM-1x16.nam    (LSTM 1×16, ~25KB)
#     - BossLSTM-2x8.nam     (LSTM 2×8, ~19KB)
#     - tw40_blues_deluxe_deerinkstudios.json (WaveNet legacy, ~163KB)
#
# ── 2. Verificar que os modelos estão presentes ────────────────────────
#
#   Os testes procuram os modelos em:
#     <CARGO_MANIFEST_DIR>/github.com/mikeoliphant/NeuralAudio/Utils/Models/
#
#   Se o repositório C++ de referência foi clonado corretamente como
#   subdiretório (ou symlinked), os modelos já estarão no local esperado.
#
#   Para verificar:
#     $ ls github.com/mikeoliphant/NeuralAudio/Utils/Models/*.nam
#
#   Deve listar pelo menos: BossWN-standard.nam e BossLSTM-1x16.nam
#
# ── 3. Baixar modelos adicionais (opcional) ────────────────────────────
#
#   Se quiser testar com outros modelos (ex: Lite, ou modelos de terceiros):
#
#   a) Baixe arquivos .nam de https://tonehunt.com/
#   b) Copie o arquivo para:
#        github.com/mikeoliphant/NeuralAudio/Utils/Models/<nome>.nam
#   c) Altere os testes para referenciar o novo arquivo, ou crie testes
#      novos seguindo o padrão dos existentes.
#
# ── 4. Executar testes completos ───────────────────────────────────────
#
#   # Compila e roda todos os testes (modelos presentes aparecem como OK)
#   cargo test
#
#   # Para ver quais testes foram skippados (stderr):
#   cargo test 2>&1 | grep SKIP
#
#   # Para rodar benchmarks criterion (requer modelos):
#   cargo bench --bench inference_bench
#
# ── 5. Golden Vectors (cross-validation numérica C++ ↔ Rust) ──────────
#
#   Os testes test_golden_vectors_wavenet e test_golden_vectors_lstm
#   procuram arquivos binários em tests/fixtures/:
#     - golden_wavenet_standard.bin
#     - golden_lstm_1x16.bin
#
#   Se estes arquivos não existirem, os testes imprimem SKIP.
#   Para gerá-los, compile e execute o utilitário C++:
#     $ bash utils/golden_gen_build.sh
#
#   O script compila o golden_gen.cpp usando os headers do NeuralAudio e
#   gera os binários de referência automaticamente.
#
# ── 6. Topologias suportadas ────────────────────────────────────────────
#
#   WaveNet: Standard(CH=16), Lite(CH=12), Feather(CH=8), Nano(CH=4)
#   LSTM:    1×8, 1×12, 1×16, 1×24, 2×8, 2×12, 2×16
#
#   Modelos com topologias fora dessas serão rejeitados pelo dispatcher.
# ============================================================================
